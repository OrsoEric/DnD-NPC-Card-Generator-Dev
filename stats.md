### Core NPC Stat Sheet – Quick‑Reference Table

| Attribute | Formula (how it’s calculated) | Note on Use |
|-----------|-------------------------------|-------------|
| **Hit Points (HP)** | `Total = HP dice + CON mod × level`<br>*(e.g., 1d8+2 per level for a Medium fighter)* | Determines how much damage the NPC can take before falling unconscious or dying. |
| **Armor Class (AC)** | `Base AC + armor bonus + shield bonus + proficiency (if wearing armor)`<br>*(e.g., 10 + DEX mod + proficiency for leather armor)* | Reflects how difficult it is to hit the NPC with an attack. |
| **Initiative** | `DEX mod + initiative bonus`<br>*(bonus from feats, magic items, etc.)* | Decides order of actions in combat before the first round. |
| **Passive Perception** | `10 + WIS mod + proficiency (if perceptive)` | Used by enemies to spot or track the NPC without actively searching. |
| **Speed** | `Base walking speed + other speeds`<br>*(e.g., 30 ft, plus 20 ft fly if flying)* | Determines how far the NPC can move in one turn. |
| **STR / DEX / CON / INT / WIS / CHA** | *6–20* (or higher for special creatures) | Core ability scores that influence saves, attacks, skills, and various abilities. |
| **Proficiency Bonus** | `+2 (1‑4)`, `+3 (5‑8)`, `+4 (9‑12)`, `+5 (13‑16)`, `+6 (17‑20)` | Added to attacks, saves, and skills the NPC is proficient in. |
| **Saving Throw Bonus** | `Ability mod + proficiency (if proficient)`<br>*(e.g., STR mod + proficiency for a Strength save)* | Used when an effect requires the NPC to resist or overcome a challenge. |
| **Skill Proficiencies** | `Ability mod + proficiency (if skilled)`<br>*(e.g., Insight = WIS mod + prof)* | Determines how well NPC can perform tasks like stealth, perception, etc. |
| **Attack Bonus** | `Weapon attack bonus = Ability mod (STR or DEX) + proficiency (if proficient)` | Added to the roll when the NPC makes an attack. |
| **Damage Die** | `Weapon’s damage die + ability mod`<br>*(e.g., 1d8 + STR for a longsword)* | The amount of damage dealt on a hit before modifiers are applied. |
| **Spellcasting Ability / Spell Save DC** | `10 + spellcasting mod + proficiency (if proficient)` | For NPCs that cast spells; used to determine how hard it is to resist them. |
| **Resistances** | *List of damage types the NPC takes half damage from* | Reduces incoming damage by 50 % for those types. |
| **Immunities** | *List of damage types the NPC takes no damage from (unless specified otherwise)* | The NPC ignores or is unaffected by attacks dealing these damage types. |
| **Weaknesses** | *Damage type that deals double damage* | Increases damage taken from that source by 100 %. |

> **Tip:** When an NPC’s stat sheet lists a “Bonus” for an attribute (e.g., +2 to Strength), add it directly to the corresponding ability score before calculating modifiers.
